# SHOHEI OISHI Portfolio V2

現行ポートフォリオを複製した、独立したローカルプロジェクトです。元のGitリポジトリやVercelプロジェクトへの接続設定は含めていません。

## 起動と確認

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

初期コミット `Initial copy from current portfolio` は、構成変更前の表示に戻すための基準点です。

## AI CREATIVE の素材

MOGU、AURA、Lumen、ClaruTaskに加え、現行ポートフォリオにあるVOLTとÉTOILEを表示しています。MirizeとワイヤレスイヤホンCMの完成動画・サムネイルは複製元および確認した素材フォルダで見つからなかったため、作品名や内容を仮に作っていません。素材が届けばV2側で差し替えられます。
